# Privacy

This site doesn't collect anything about you. There are no accounts, no forms, no cookies, no analytics and no tracking.

- **Hosting.** The site is hosted on GitHub Pages. Like any web server, GitHub may keep standard logs of requests, such as IP addresses, for security. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **Fonts.** The typefaces load from Google Fonts, so your browser contacts Google when a page opens. See [Google's privacy policy](https://policies.google.com/privacy).
- **The feed.** Following the RSS feed happens entirely in your feed reader. Nothing about you reaches this site.
- **Email.** If you write to {{ site.email }}, your message is kept only to reply to you and is never shared.

Questions? Write to [{{ site.email }}](mailto:{{ site.email }}).
